## 🚀 Quick Start

### Prerequisites
- **Node.js** (versi 16 atau lebih baru)
- **npm** atau **pnpm**

### Installation

1. **Clone repository:**
   ```bash
   git clone <repository-url>
   cd xss-test
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # atau
   pnpm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   # atau
   pnpm dev
   ```

4. **Buka browser:**
   ```
   http://localhost:3002
   ```
   
   > **⚡ INSTANT DEMO**: Aplikasi langsung menampilkan search bar dengan tombol demo XSS!

## 🔧 Customization

### Menambah Payload Baru
Edit file `constants.tsx` dan tambahkan ke array `XSS_PAYLOADS`:

```typescript
{
  category: "Custom",
  label: "My Payload",
  payload: "<script>/* your payload */</script>",
  description: "Deskripsi payload Anda"
}
```

### Menambah Artikel Blog
Tambahkan artikel baru ke array `BLOG_POSTS` di `constants.tsx`:

```typescript

  id: 4,
  title: "Judul Artikel",
```
